# Pixel Fighter Bot для L2 LU4 (на базе Arduino Leonardo)

Мой персональный проект автоматического кликера для Lineage 2 LU4. Бот написан на Python и использует аппаратную эмуляцию нажатий клавиш через плату **Arduino Leonardo / Micro** (на чипе ATmega32U4), что делает его полностью невидимым для внутриигровых защит, так как операционная система видит сигналы от стандартной USB-мыши и клавиатуры.

В отличие от классических ботов на OpenCV, этот скрипт использует **технологию пиксельного анализа цвета**, что снижает нагрузку на процессор до 0% и обеспечивает мгновенный отклик.

## 🚀 Основные возможности

* **Аппаратное управление**: Сигналы клавиатуры и мыши идут напрямую из контроллера Arduino.
* **Пиксельный детект**: Бот отслеживает здоровье моба по конкретной точке левого края HP-бара. Ему не важен размер полоски и процент оставшегося здоровья — он бьет цель до последнего.
* **Защита от мигания интерфейса**: Двойная проверка пикселя защищает от случайного сброса таргета во время анимаций критов или дебаффов.
* **Интеллектуальный тайм-аут**: Если моб не умирает за 30 секунд (персонаж застрял или цель слишком толстая), бот автоматически сбрасывает бой и ищет новую цель.
* **Глобальная пауза**: Нажатие клавиши `[F9]` мгновенно останавливает или возобновляет работу бота из любого окна системы.
* **Удобная калибровка**: Встроенный скрипт для снятия координат и RGB-цветов прямо с экрана без необходимости вручную резать скриншоты.

## 🛠 Архитектура проекта и алгоритм работы

1. Бот отправляет команду `2` в Arduino.
2. Arduino на аппаратном уровне зажимает клавишу `F2` ровно на **500 мс** для поиска живого моба через внутриигровой макрос/функцию.
3. Python проверяет калиброванную точку HP:
   * Если точка стала **красной** (моб найден) — начинается цикл атаки.
   * Если точка пустая — бот делает небольшую паузу и пробует искать снова.
4. Во время атаки Python с интервалом отправляет команду `4` (`F4` — боевое умение/атака).
5. После каждого удара проверяется точка Черепа:
   * Если зафиксирован цвет **красной окантовки черепа** — моб мертв, цикл завершается, бот идет искать заново.
   * Если за 30 секунд моб не умер — срабатывает тайм-аут, цель сбрасывается.

## 📦 Инструкция по установке и настройке

### Шаг 1: Прошивка Arduino
Загрузи скетч (находится в проекте) в плату через Arduino IDE. Убедись, что скорость порта выставлена на `115200` бод, так как на этой скорости обеспечивается потокобезопасная связь без таймаутов.

### Шаг 2: Установка зависимостей на ПК
Убедись, что у тебя установлен Python 3.x, активируй виртуальное окружение и установи библиотеки:
```bash
pip install -r requirements.txt
```

### Шаг 3: Калибровка точек (Запуск `get_points.py`)
Перед первым запуском бота необходимо привязать координаты твоего монитора и интерфейса игры.
1. Запусти скрипт: `python get_points.py`.
2. Переключись на игру. Выдели живого моба с **полным ХП**.
3. Наведи курсор мыши на **самый левый край (кончик)** красной полосы HP таргета и удерживай мышь 5 секунд, пока скрипт не пикнет/сохранит точку.
4. Убей моба. Наведи курсор на **красную окантовку иконки черепа** мертвого моба и удерживай мышь 5 секунд.
5. Настройки автоматически запишутся в файл `bot_config.ini`. В нем же при необходимости можно вручную изменить COM-порт (по умолчанию `COM4`).

### Шаг 4: Запуск бота
Убедись, что игра открыта, и запусти основного бота:
```bash
python bot.py
```
Переключись на окно игры. Чтобы остановить бота в любой момент или отойти от ПК, нажми клавишу **`[F9]`**. Чтобы полностью закрыть скрипт, нажми **`Ctrl + C`** в окне консоли.
